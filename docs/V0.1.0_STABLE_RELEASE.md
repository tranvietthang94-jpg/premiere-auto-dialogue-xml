## Phạm vi stable

`v0.1.0` khóa sản phẩm sau Phase 16: app Windows offline nhận Final Cut Pro XML từ Premiere, phân tích đúng source WAV trên timeline, giữ lời và vùng mơ hồ, Disable noise/bleed rõ ràng, cân sample peak từng phrase theo routing đã khóa và xuất XML/audit mới. Production writer được phép chèn tối đa 12 Constant Gain một frame khi boundary qua source-peak gain-safety fail-closed.

Stable không mở thêm preview, playback, cloud, telemetry, stereo source, sample rate/routing mới, fractional frame rate, drop-frame, nested/multicam, retime, effect, automation hoặc submix. `-6 dBFS` vẫn là sample peak theo phrase sau profile routing đã kiểm chứng, không phải LUFS, true peak, limiter hay cam kết Master bus.

## Quy trình phát hành

1. Thay đổi stable chỉ gồm tài liệu/metadata, đi qua pull request và toàn bộ workflow `Build and test`.
2. Merge bằng merge commit; post-merge `main` phải đạt cùng build/test/policy/publish/installer smoke.
3. Tag annotated `v0.1.0` trỏ đúng post-merge `main` đã đạt CI.
4. GitHub Release chỉ chứa release notes và source do GitHub sinh tự động; không upload installer, ZIP, XML, WAV, `.prproj`, chứng thư hoặc private artifact.
5. Bộ cài dùng thật được build và ký cục bộ từ đúng commit tag bằng chứng thư nội bộ hiện hành, sau đó chạy cài/mở/xác minh payload/gỡ với `scripts/test-installer.ps1`.
6. Gói local stable gồm installer, public `.cer`, manifest, báo cáo smoke, hai hướng dẫn và checksum; `privateKeyIncluded=false`. Exact commit và SHA-256 nằm trong manifest local và release notes.

## Điều kiện sử dụng và rollback

- Chỉ dùng trên input nằm trong hợp đồng đã khóa; input không hỗ trợ phải dừng trước output.
- XML, WAV và `.prproj` nguồn luôn bất biến; mỗi lần chạy tạo thư mục mới.
- Chứng thư tự ký chỉ dành cho máy nội bộ đã trust đúng public `.cer`; không đại diện public CA hoặc SmartScreen reputation.
- Nếu phát hiện regression, giữ nguyên gói `v0.1.0`, không ghi đè. Sửa trên version mới, chạy lại evidence tương xứng và phát hành patch version.
